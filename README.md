# Editorial Web Craft has moved

This repository is archived and no longer updated. Editorial Web Craft now lives in the **fkweb-dev** marketplace, together with Fernando Kylas's other Claude Code plugins:

**https://github.com/fernandokylas/fkweb-dev**

Install it from there:

```bash
claude plugin marketplace add fernandokylas/fkweb-dev
claude plugin install editorial-web-craft@fkweb-dev
```

If you installed it from this repository, remove the old copy first:

```bash
claude plugin uninstall editorial-web-craft@editorial-web-craft
claude plugin marketplace remove editorial-web-craft
```

The history up to 1.0.1 stays here (tag `v1.0.0` marks 1.0.0). Newer versions and the changelog are in the marketplace.
